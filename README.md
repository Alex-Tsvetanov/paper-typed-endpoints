# typed-endpoints

Unary protobuf and gRPC endpoints generated by C++26 static reflection (P2996) from `.proto` text,
without `protoc`. Research code for a paper on compile cost and end-to-end performance against
`protoc`-generated code. Pre-release: nothing here is a measured result.

```cpp
struct greeter_proto {
    static constexpr char data[] = {
#embed "greeter.proto"
        , '\0'};
    static constexpr std::string_view text{data, sizeof data - 1};
};
consteval { tep::define_messages<greeter_proto>(); }
using HelloRequest = tep::message_t<greeter_proto, "demo.HelloRequest">;
using HelloReply = tep::message_t<greeter_proto, "demo.HelloReply">;

struct greeter {
    HelloReply SayHello(const HelloRequest& q) { return {"hello " + q.name}; }
};
greeter impl;
tep::endpoint<greeter_proto, "demo.Greeter", greeter> ep{impl};
// ep.invoke("/demo.Greeter/SayHello", request_bytes, framed_response);
```

## Layout

- `include/tep/schema.hpp`, `wire.hpp`, `grpc.hpp`: portable C++23 (GCC, clang, MSVC).
- `include/tep/reflect.hpp`: the reflection layer. It needs `__cpp_impl_reflection` (GCC 16 with
  `-std=c++26 -freflection`) and refuses to compile without it.
- `tests/`: functional tests, golden wire vectors from `protoc` (`tests/golden/README.md`), and
  compile-fail tests.
- `design/`: the design note (draft) and compiler findings.

## Build

```
cmake --preset linux-gcc-debug && cmake --build build/linux-gcc-debug && ctest --test-dir build/linux-gcc-debug
```

Presets: `linux-gcc-{debug,release,asan}`, `linux-clang-{debug,asan}` (portable layers only),
`mingw-gcc-{debug,release}` (MinGW-w64 GCC 16 first on PATH; all layers on Windows),
`msvc-{debug,release,asan}` (portable layers only; MSVC has no P2996).
